## 四、已知边界

- 无头软件渲染下 FPS 读数偏低（7-8），真实 GPU 环境流畅；低分辨率流体缓冲按画质档位自适应。
- 首次进入旅程如被浏览器自动播放策略拦截，右下角出现「开启声音」引导按钮，一次点击解锁。
- `file://` 直开受 ES Modules 协议限制，需任意静态服务器（见 README 启动命令）。
