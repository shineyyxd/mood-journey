### 数据流（一次完整旅程）

1. **输入心情** → `mood/parse` → DeepSeek（约 4 秒）→ 起点坐标 + 候选终点 → **确认屏**「接住你了」（3 秒自动出发）
2. **出发** → `journey` → 情绪弧线生成 → DeepSeek 沿弧选歌 → 网易云侧载解析播放地址（VIP cookie + realIP 伪装）→ WebSocket 推送歌单
3. **播放** → 浏览器经 `/api/stream?id=` 分段下载（Range 206），唱片自转、光点沿弧线推进、三行歌词同步
4. **行为回流** → 切歌/共鸣/感觉不准/听完 → SQLite → `/api/admin/overview` 数据后台

### 架构哲学

**模型负责表现层，代码负责真相层**：LLM 只做两次调用（推断+选歌），弧线、数据、播放全是确定性代码——便宜（单次旅程几厘钱）、快（4 秒接住）、可控。

## 二、版本演化史

```
v0  DJ电台时代        AI DJ 语音播报+串场（已删，教训：人声出戏）
v1  无旁白重建        基础链路：输入→推断→选歌→播放
                      │
v2.0 黑胶视觉实验     ├─ Canvas 唱片盘面（盘面=Russell平面）
                      ├─ 弧线+呼吸光点
                      ├─ 五套皮肤
                      │
v2.1 盘面合一         ├─ 弧线收进盘面、唱片自转跟随播放
                      │
v2.2 合体上线         ├─ 方案C「左文右盘」编辑排版
                      ├─ 真后端合体：Express + SQLite + LLM 推断 + 网易云真歌
                      ├─ 交叉淡化切歌、数据打点闭环、WebSocket 进度广播
                      │
v2.3 首批反馈修复     ├─ iOS 手势音频解锁
                      ├─ VIP 30s 截断过滤
                      ├─ 默认皮肤改暮色、文字提亮、移动端降载
                      │
v2.4 二批反馈修复     ├─ 标题「说说此刻的心情」
                      ├─ 超时重试纱幕、真 scrubber、去术语化
                      ├─ chips 缓存 + 限流重试（并发三层）
                      ├─ LLM 换 DeepSeek v4-flash（推断 2分钟→4秒）
                      │
v2.5 去噪音           ├─ 确认屏替代分歧屏（一次决策+一次确认）
                      ├─ 删预设chips、「感觉不准？」出口
                      ├─ P0 音频：Range 206 续传 + 流地址按ID保鲜
                      │
v2.5.1 体验回补       ├─ 盘面拖拽恢复（6px防误触）
                      ├─ VIP cookie 接入（曲库扩到 VIP）
                      └─ 三行窗口同步歌词
```

### 迭代的三层结构

- **骨架**（v1-v2.2）：把"接住→引导"这条命造出来
- **皮囊**（v2.0-v2.5）：黑胶盘面、排版、皮肤、文案——氛围感
- **筋肉**（v2.3-v2.5.1）：音频链路、并发、VIP、歌词——真实用户逼出来的强度
